# Study Time Analyzer

## Description

Study Time Analyzer is a Python program that helps students look at the relationship between their grades and the amount of time they spend working on assignments.

The student can enter:
- Course name
- Assignment name
- Grade percentage
- Hours spent working or studying

The program saves the information and analyzes each course.

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

python study_time_analyzer.py

## Main Features

1. Add assignment information.
2. View saved assignments.
3. View the average grade for each course.
4. View total study/work time.
5. Compare grades with study time.
6. Save information between program runs.

## Example

A student could enter:

Course: CSE111
Assignment: Exam 1
Grade: 82
Hours: 4

The program will save the information and use it when calculating the course analysis.
